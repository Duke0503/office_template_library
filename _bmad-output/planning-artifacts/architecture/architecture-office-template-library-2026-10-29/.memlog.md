- (direction) Fast path chosen: user asked to proceed straight to implementation (2026-10-29). Spine is the build contract and the README architecture source; no extra rendering requested.
- (constraint) Inherited from SPEC: template originals immutable; one engine for all kinds; ONLYOFFICE Community via Docker; one docker compose command; English UI; DOCX+PPTX only, files by server id; 6-8 h budget.
- (constraint) Inherited from domain model: contexts catalog, workspace, editor-integration (D1); template revisions (D2); shared categories (D3); archived templates keep documents working (D4).
- (decision) AD-1 Paradigm: modular monolith, hexagonal per bounded context. Modules catalog, workspace, editor (ONLYOFFICE ACL). Domain code imports no framework, DB, fs or ONLYOFFICE code. Prevents business rules leaking into routes and adapters.
- (decision) AD-2 Template immutability: runtime code gets a read-only TemplateStore port (no write methods); only the importer gets a writer; stored template files are chmod 0444; copy-on-create verifies sha256. Prevents any edit path touching an original.
- (decision) AD-3 Kind registry: one registry in packages/shared maps kind to extension, MIME, ONLYOFFICE documentType (word/slide). No kind branching outside it. Prevents a second kind-switch drifting and keeps XLSX a one-entry change.
- (decision) AD-4 Template source of truth is templates/manifest.json plus files and committed previews in the repo; the import command upserts the DB and stores files under templates/{id}/r{revision}/; a changed checksum makes a new revision. Runs on api start and via CLI. Prevents UI or DB becoming a second source.
- (decision) AD-5 Data ownership: catalog owns templates and categories tables; workspace owns documents; workspace reads catalog only through the TemplateSource port, no cross-module joins. One SQLite file, Drizzle schema per module.
- (decision) AD-6 Document mutation only through workspace commands (create, saveEditedVersion). A save writes documents/{id}/v{n}.{ext}, then updates the row in one transaction; editorKey = {id}-v{n}. Prevents stale editor cache and half-written versions.
- (decision) AD-7 ONLYOFFICE contract: JWT on with ONLYOFFICE_JWT_SECRET; api signs editor config; DS fetches files from api over the compose network with a short-lived signed URL; callback POST /api/editor/callback/:documentId verified before any write; DS env ALLOW_PRIVATE_IP_ADDRESS=true. Prevents unsigned saves and browser-vs-container URL confusion.
- (decision) AD-8 API contract: REST JSON under /api; zod schemas in packages/shared validate requests in api and type the web client; error envelope {error:{code,message}} with UPPER_SNAKE codes; UUID ids; ISO-8601 UTC dates.
- (decision) AD-9 File access by id only: storage keys are server-generated; the storage adapter rejects keys that resolve outside its root; import checks ZIP magic bytes and the OOXML main content type for the kind; no upload endpoint.
- (decision) AD-10 Frontend: React SPA, routes /templates/:kind, /documents, /documents/:id/edit; server state only via TanStack Query; gallery filters live in the URL; UI from shadcn/ui per ui-shadcn skill.
- (decision) AD-11 Deployment: docker compose with two services, documentserver (onlyoffice/documentserver:9.3.0) and app (Express serving the built SPA and API); named volume for SQLite and storage; .env.example documents every variable. Dev: Vite with proxy plus DS from compose.
- (decision) AD-12 Testing: Vitest unit tests for domain; Supertest API tests with temp storage and a fake EditorGateway covering copy isolation by checksum, revision import, not-found, bad-JWT callback rejection and path traversal.
- (decision) Seed templates are generated by scripts with docx (MIT) and pptxgenjs (MIT), so content is self-authored; previews rendered through the DS conversion API (thumbnail first=false returns all pages) and committed.

- (decision) AD-7 amended: callback token read from Authorization Bearer (payload claim) or body token; only verified claims are trusted. Reply {error:0} only after the save commits, {error:1} otherwise. Every URL DS returns has its origin rewritten to DOCSERVER_INTERNAL_URL and only that host is fetched. - (decision) AD-13 Template revision snapshot: TemplateSource returns one descriptor (templateId, revision, kind, name, storageKey, sha256); DocumentFactory copies by that storageKey and verifies that sha256. Catalog adds a template_revisions table unique on (templateId, revision). Importer stores file, verifies checksum, then commits the row. SQLite WAL with busy_timeout 5000. Startup import finishes before the server listens.
